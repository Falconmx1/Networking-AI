# Networking AI 🤖🔌

Herramienta CLI para análisis de red con inteligencia artificial.  
Compatible con **Linux** y **Windows**.

## 🚀 Instalación rápida

```bash
# Clonar repo
git clone https://github.com/Falconmx1/Networking-AI.git
cd Networking-AI

# Instalar dependencias
pip install -r requirements.txt

🎯 Comandos finales disponibles:
# Linux/Mac
python src/cli/main.py monitor --packets 20
python src/cli/main.py scan --target 192.168.1.0/24
python src/cli/main.py predict
python src/cli/main.py recommend
python src/cli/main.py help

# Windows (PowerShell)
python src/cli/main.py monitor --packets 20
